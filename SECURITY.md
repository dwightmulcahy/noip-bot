# Security Policy

## Supported versions

Only the latest published release receives security updates. Upgrade to the
newest semantic-versioned Docker image before reporting a problem.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository when
available. If it is unavailable, open an issue requesting a private contact
channel without including exploit details, credentials, tokens, hostnames, or
captured screenshots.

Please include the affected version, deployment architecture, impact, and
minimal reproduction steps. Do not test against systems or accounts you do not
own or have permission to assess.

Never commit No-IP credentials, Gmail app passwords, status tokens, .env files,
browser profiles, screenshots, or persisted state.
